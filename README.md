# Olá, eu sou Victor Hugo Forzani 👋

Eu transformo tarefas manuais repetitivas em automações simples que rodam sozinhas.

## O que eu construo
- **Organizadores de arquivos** — a pasta bagunçada arruma sozinha, sem sobrescrever nada
- **Relatórios automáticos** — a planilha entra, o resumo pronto sai (total, mês, top produtos)
- **Monitores e bots** — aviso de preço, estoque, mensagem ou prazo, na hora que muda
- **Integrações** — sistemas que conversam entre si, sem copiar-e-colar

## Como funciona contratar
1. Você me mostra a tarefa chata (print ou vídeo do celular)
2. Fechamos preço e prazo por escrito
3. Você recebe o script + um vídeo curto ensinando a usar
4. 7 dias de ajustes inclusos
